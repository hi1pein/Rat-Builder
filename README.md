## 📋 О проекте

**RAT Builder** — это автоматический инструмент для создания скрытых агентов удалённого управления (RAT) на языке Python с последующей компиляцией в исполняемый файл Windows. Проект разработан для **образовательных целей** и демонстрирует:

- Техники шифрования полезной нагрузки (AES-256).
- Обход сигнатурных антивирусных детектов через шифрование и выполнение в памяти.
- Работу с сетевыми протоколами (TCP, HTTP).
- Автоматизацию сборки EXE через PyInstaller.
- Управление клиентом через командную строку.

Инструмент может использоваться для:
- Тестирования защищённости собственных систем.
- Изучения методов обнаружения и противодействия вредоносному ПО.
- Проведения легальных пентестов с разрешения владельца системы.

## 🚀 Возможности билдера

1. **Автоматическое определение публичного IP** (через 3 независимых сервиса) или поддержка доменов (DDNS).
2. **Автоустановка зависимостей** (cryptography, pyinstaller, miniupnpc) при запуске.
3. **Добавление правил в Windows Firewall** для открытия необходимых портов.
4. **Проброс портов через UPnP** (если роутер поддерживает) с выводом инструкции для ручного проброса.
5. **Генерация зашифрованного payload** (AES-256) со случайным ключом (каждая сборка уникальна).
6. **Создание загрузчика (stager)**, который:
   - Отключает Windows Defender.
   - Отключает диспетчер задач (Task Manager).
   - Добавляет себя в автозагрузку.
   - Регистрирует клиента на сервере по уникальному UUID.
   - Скачивает и выполняет основной RAT в памяти (без сохранения на диск).
7. **Сборка одного EXE-файла** через PyInstaller (скрытый режим).
8. **Генерация серверной части** (HTTP + командный сервер в одном скрипте).
9. **Автоматический запуск сервера** в новом окне CMD.
10. **Проверка доступности сервера извне** после сборки.

## 📡 Команды клиента (RAT)

После запуска агента сервер получает управление и принимает следующие команды:

| Команда | Описание |
|---------|----------|
| `SYSINFO` | Собрать информацию о системе (ОС, CPU, RAM, диски). |
| `PROCESSES` | Список запущенных процессов (PID и имя). |
| `KILL <PID>` | Завершить процесс по его PID. |
| `CLIPBOARD` | Получить содержимое буфера обмена. |
| `DRIVES` | Список логических дисков (C:\, D:\...). |
| `PWD` | Показать текущую рабочую директорию. |
| `LIST` | Вывести содержимое текущей папки с номерами, размерами и датами. |
| `CD <путь>` или `CD <номер>` | Перейти в указанную папку (или по номеру из LIST). |
| `CD ..` | Перейти на уровень выше. |
| `GETFILE <путь>` | Скачать файл с клиента на сервер (с прогресс-баром). |
| `GETFOLDER <путь>` | Скачать папку (упаковывается в ZIP и отправляется). |
| `SCREENSHOT` | Сделать скриншот рабочего стола и сохранить на сервере. |
| `EXEC <команда>` | Выполнить любую системную команду (cmd/PowerShell) на клиенте. |
| `REBOOT` | Перезагрузить компьютер клиента. |
| `SHUTDOWN` | Выключить компьютер клиента. |
| `PERSIST` | Добавить агент в автозагрузку (если не сработало автоматически). |
| `DISABLE_TASKMGR` | Отключить диспетчер задач на клиенте. |
| `QUIT` | Завершить работу клиента. |
| `/quit` | Завершить работу сервера. |
